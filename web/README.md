# Auto-Novel Skill · Web 界面

> 把命令行版的 Auto-Novel 变成浏览器版——小白用户的最佳入口。

---

## 🚀 30 秒启动

```bash
cd ~/.hermes/profiles/cont/skills/auto-novel/web
python3 app.py
```

**浏览器访问**：http://localhost:7860

**或使用启动脚本**：

```bash
./start.sh
```

---

## 📱 4 大功能页面

### 📊 页面 1：项目仪表盘

**功能**：
- 查看当前项目状态（字数、章节、进度）
- 显示 5 维评分（带可视化进度条）
- 章节列表（已完成的章节一览）
- 连胜记录（连续日更天数）

**适合**：日常查看进度

### ✍️ 页面 2：章节生成

**5 步完整流程**（基于 5 个核心协议）：
1. **Step 1：选题** —— 4 连问 + 3 差异化选题
2. **Step 2：大纲** —— 3 层大纲 + Save the Cat
3. **Step 3：目录** —— 章节目录 + 5 大标题类型
4. **Step 4：草案** —— 6 大要素 + 用户审阅
5. **Step 5：正文** —— 9 步流程 + 自动评分

**适合**：从 0 到第 1 章的完整流程

### 📊 页面 3：5 维评分可视化

**功能**：
- 5 维评分详情（人设/世界观/逻辑/文风/重复度）
- 详细分析（每维的子项）
- 改进建议（自动生成）
- 阈值提示（≥9.0 通过 / 7.0-8.9 复审 / <7.0 重写）

**适合**：章节完成后查看质量

### 💡 页面 4：创作辅助

**4 大辅助功能**：
1. **🆘 卡文急救** —— 输入卡点，AI 提供 3 方向
2. **📅 日更管理** —— 查看进度 + 设置目标
3. **🎨 文风蒸馏** —— 粘贴段落，AI 分析你的风格
4. **🤝 AI 共写** —— 你一句我一句（开发中）

## 🛠 安装

### 前置条件

```bash
python3 >= 3.8
gradio >= 4.0
```

### 安装 gradio

```bash
pip install gradio
```

或使用启动脚本自动安装。

### 启动服务

```bash
# 方式 1：直接启动
python3 app.py

# 方式 2：使用启动脚本
./start.sh

# 方式 3：自定义端口
python3 app.py --server-port 8080
```

## 🔧 配置

### 修改端口

```python
# app.py 末尾
demo.launch(server_port=8080)
```

### 修改主题

```python
# app.py build_interface()
theme = gr.themes.Soft(primary_hue="indigo")  # 可改为 green/red/blue
```

### 修改数据存储

默认使用 `ProjectStore` 模拟数据。生产环境应改为：

```python
# 接入真实数据
from skill_dir.protocols.knowledge_base_contract import load_project
store = load_project(project_name)
```

## 🐛 故障排查

### gradio 安装失败

```bash
pip install gradio --upgrade
```

### 端口被占用

```bash
lsof -i :7860
kill <PID>
```

或换端口：

```bash
python3 app.py --server-port 8080
```

### 中文乱码

```python
# app.py 顶部
import locale
locale.setlocale(locale.LC_ALL, 'zh_CN.UTF-8')
```
