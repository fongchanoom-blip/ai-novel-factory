# 日更管理协议（Daily Management Mode）

[REF:protocol.daily_management]

## 一、设计哲学

**核心原则**：**"帮助网文作者坚持日更，提高更新稳定性"**

网文作者最大的痛点之一是**日更压力**——每天必须更新 5000 字，否则影响推荐、读者流失。

**为什么需要日更管理？**
- 番茄/起点的算法对"断更"敏感（断更 1 天 = 推荐位下降）
- 写作者容易拖延（"明天再写"心态）
- 需要目标可视化 + 进度追踪 + 鼓励反馈

**核心策略**：
- ✅ **目标可视化**：每日目标 / 已完成 / 剩余
- ✅ **进度追踪**：本周/本月累计
- ✅ **断更预警**：连续 2 天未更新 = 警告
- ✅ **鼓励反馈**：每完成一次 = 庆祝

## 四、核心功能详解

### 4.1 每日目标设置

```yaml
默认目标:
  番茄系: 4000 字 (2 章 × 2000 字)
  起点系: 5000 字 (1 章 × 5000 字)
  晋江系: 4000 字 (1 章 × 4000 字)
  知乎系: 10000 字 (短篇)

用户自定义:
  /novel:daily set <字数>
  /novel:daily set chapters <章节数>
```

### 4.2 进度追踪

**追踪维度**：

| 维度 | 范围 | 更新频率 |
|------|------|----------|
| 今日 | 0:00 - 23:59 | 实时 |
| 本周 | 周一 - 周日 | 每日 0:00 |
| 本月 | 1 号 - 月末 | 每日 0:00 |
| 总计 | 项目开始 - 现在 | 实时 |

### 4.3 断更检测

```python
# 逻辑（伪代码）
def check_daily_break():
    last_update = get_last_chapter_date()
    today = datetime.now().date()
    days_diff = (today - last_update).days

    if days_diff == 1:
        # 昨天未更新
        if user.preferences.warnings_enabled:
            notify("⚠️ 你昨天没写，今天要补上哦")
    elif days_diff >= 3:
        # 连续 3 天未更新
        notify("🚨 你已经 3 天没写了！建议：")
        notify("1. 调整目标（降低字数）")
        notify("2. 使用 /novel:stuck 卡文急救")
        notify("3. 使用 /novel:cowrite AI 共写")
```

### 4.4 鼓励反馈

**分级反馈**：

| 触发 | 反馈 |
|------|------|
| 完成日更 | 🎉 恭喜！[emoji 庆祝] |
| 连续 7 天 | ⭐ 一周连续日更！[成就解锁] |
| 连续 30 天 | 🏆 一个月！[里程碑] |
| 字数突破 | 📚 [里程碑，如"10 万字达成"] |
| 完成度 > 100% | 💪 超出预期！ |
| 落后 1 天 | 💡 加油，今天补上！ |
| 落后 3 天 | 🚨 警告（但不批评） |

## 七、智能建议

### 7.1 基于进度的建议

```python
# 伪代码
def get_smart_suggestion(progress):
    if progress.today < progress.target * 0.3 and progress.now_hour > 18:
        # 下午 6 点后低于 30% 目标
        return "💡 你今天落后了，要不要用 /novel:stuck 卡文急救？或者用 /novel:cowrite AI 共写？"
    elif progress.week < progress.weekly_target * 0.5 and progress.now_day > 3:
        # 周三后低于 50% 周目标
        return "💡 本周进度落后，建议明天多写一些"
    elif progress.streak >= 30:
        return "🔥 你已经连续 30 天日更！太厉害了！"
    elif progress.streak == 0:
        return "🤗 没关系，从今天开始重新开始！"
```

### 7.2 鼓励 vs 警告的平衡

```yaml
鼓励场景（积极反馈）:
  - 完成日更
  - 连续天数增加
  - 字数突破
  - 章节完成

温和提醒场景:
  - 落后 1 天：💡 加油
  - 落后 2 天：🤔 怎么了？
  - 落后 3 天：🚨 建议调整

绝不:
  - 批评用户
  - 强迫用户
  - 给"必须"的压力
```

## 九、平台适配

### 9.1 各平台的日更标准

| 平台 | 标准日更 | 字数要求 |

你的目标（5000 字）适合起点系 📖
