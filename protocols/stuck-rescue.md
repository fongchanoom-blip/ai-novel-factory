# 卡文急救协议（Stuck Rescue Mode）

[REF:protocol.stuck_rescue]

## 一、设计哲学

**核心原则**：**"卡文时给创作者 3 个方向 + 片段，立即可用"**

这是网文创作者最大的痛点——卡文。作者写到第 N 章不知道下一章写什么，可能持续几天写不出来。

**为什么需要卡文急救？**
- 番茄/起点日更压力下，卡文 1 天 = 断更 = 影响推荐位
- 创作者半夜卡文，找不到人讨论
- 需要立即的灵感，不是"等明天再想"

**核心策略**：
- ✅ **3 个方向**（不只是 1 个，避免选择困难）
- ✅ **每个方向 200 字片段**（可直接接续）
- ✅ **30 秒内给出方向**（不耽误创作）
- ✅ **支持选定后展开完整章节**

---

## 二、触发词

```
用户说：
- "/novel:stuck"
- "/novel:stuck 张三被困山洞"
- "卡文了"
- "写不下去了"
- "下一章不知道写什么"
- "stuck"
```

**特别说明**：如果用户没说具体卡在哪，自动询问。

## 三、完整流程

### 3.1 第 1 步：确定卡在哪里（5 秒）

**情况 A：用户指定了卡点**

```
用户: "/novel:stuck 张三被困山洞，下一步不知道怎么写"
   ↓
AI 直接分析问题
```

**情况 B：用户没说**

```
🤖 AI: 嘿！我来帮你。告诉我卡在哪里？

A. 不知道怎么发展下一个剧情（不知道怎么往下走）
B. 不知道怎么写出"爽感"（情节太平淡）
C. 不知道怎么高潮（这章不知道哪里该爆发）
D. 不知道怎么回收伏笔（前面埋的线索不知道用）
E. 不知道怎么打败对手（战斗不知道怎么写）

或者直接描述你的卡点 ✍️
```

### 3.2 第 2 步：分析卡点（5 秒）

**基于 7 层上下文组装**（如果有项目）：
- Layer 4：近场 3 章正文
- Layer 3：当前 50 章规划
- Layer 2：主角状态

**分析内容**：
- 主角当前状态
- 已发生事件
- 未发生事件
- 伏笔列表
- 主角动机

### 3.3 第 3 步：生成 3 个方向（20 秒）

**3 个方向的类型**（基于用户卡点）：

| 卡点类型 | 方向 A | 方向 B | 方向 C |
|----------|--------|--------|--------|
| **剧情卡** | 推进主线 | 加新支线 | 闪回/穿越 |
| **爽感卡** | 装逼打脸 | 扮猪吃虎 | 越级反杀 |
| **高潮卡** | 真相揭露 | 战斗爆发 | 情感爆发 |
| **伏笔卡** | 直接揭晓 | 暗示加深 | 反转使用 |
| **战斗卡** | 实力碾压 | 智取 | 心理战 |

### 3.4 第 4 步：输出 3 方向 + 片段（30 秒）

```
🚑 卡文急救

我看了你前面的章节，你正在写张三参加宗门大比 16 强。
当前状态：
- 张三：筑基期三层，150 灵石，透视符箓（今日 2/3 次）
- 已发生：张三赢了预选赛
- 未发生：决赛（4 章后）

我给你 3 个方向：

【方向 1：扮猪吃虎】
张三故意隐藏实力，让对手 3 招。对手以为张三弱，嘲讽他。
张三突然透视符箓发动，看到对手破绽，一击制胜。
→ 反差感强 + 爽点高
→ 后续可接"被高手关注"

片段：
"我看着眼前的赵无极，心中平静如水。
透视符箓悄然发动——他的右肩有旧伤，呼吸略有不均。
'请师兄指教。'我拱手行礼。
'你还不配让我出手。'赵无极冷哼。
我没有回答。这一刻，我等了三个月..."

【方向 2：智取胜敌】
张三意识到实力差距，正面打不过。用透视符箓看穿对手
阵法的弱点（宗门比试用阵法），智取胜利。
→ 烧脑感 + 智商碾压
→ 展示张三的机智

片段：
"我缓缓踏入阵法。透视符箓看穿幻象——这不是普通阵法，
而是'七杀阵'的变种。
'有意思。'我在心中冷笑。
赵无极，你以为能困住我？..."

【方向 3：心理战】
张三故意激怒赵无极，让他露出破绽。言语间挑拨，
对手心态崩盘，攻击变形，张三抓住机会一击制胜。
→ 文戏精彩 + 角色塑造
→ 反派塑造也立体

片段：
"'听说赵师兄曾输给外门弟子？'我笑着问。
赵无极的脸色瞬间铁青。
'你——！'
'只是听说。'我依然微笑。
他出手已经乱了..."

你选哪个方向？

A. 方向 1（扮猪吃虎）→ 展开完整章节
B. 方向 2（智取胜敌）→ 展开完整章节
C. 方向 3（心理战）→ 展开完整章节
D. 都不喜欢 → 重新生成 3 个方向
E. 混合（告诉我怎么混合）

输入 A/B/C/D/E ✍️
```

## 四、3 个方向的设计原则

### 4.1 方向 A：装逼打脸 / 扮猪吃虎

**适用卡点**：
- 不知道怎么写出"爽感"
- 不知道怎么打败对手
- 不知道怎么增加爽点

**设计要素**：
- 铺垫（30%）：示弱/嘲讽
- 转折（10%）：关键时刻
- 爆发（40%）：一击制胜
- 收束（20%）：众人反应

### 4.2 方向 B：智取胜敌 / 烧脑

**适用卡点**：
- 不知道怎么打败强敌
- 不知道怎么有创意
- 不知道怎么用伏笔

**设计要素**：
- 困境（40%）：实力差距明显
- 思考（20%）：金手指/伏笔的运用
- 破解（30%）：智取过程
- 胜利（10%）：快意收束

### 4.3 方向 C：心理战 / 文戏

**适用卡点**：
- 不知道怎么写非战斗场景
- 不知道怎么塑造反派
- 不知道怎么高潮

**设计要素**：
- 对话铺垫（40%）：言语交锋
- 情绪铺垫（20%）：心理活动
- 转折（30%）：心理破防
- 收束（10%）：战局反转

## 五、3 选 1 后：展开完整章节

```
用户选 A：
   ↓
AI: 好的，我按方向 1（扮猪吃虎）展开完整章节（3500 字）...
   ↓
（30-40 秒后）
   ↓
📖 第 12 章 大比初战

[完整 3500 字]

【5 维评分】
- 人设一致性：9.4
- 世界观一致性：9.3
- 逻辑性：9.1
- 文风一致性：9.0
- 非重复性：9.2
- 总评：9.20 ✅ 通过

💡 继续？
A. /novel:continue → 继续写下一章
B. /novel:stuck → 又卡住了
C. /novel:fix → 这一章需要调整
```

## 六、特殊场景处理

### 6.1 用户没建项目

```
用户: "/novel:stuck"
   ↓
AI: 你还没建项目呢。让我先问你几个问题：

1. 你卡在哪里？（剧情/爽感/高潮/伏笔/战斗）
2. 你想写什么？（题材 + 主角 + 金手指）

或者你想我帮你新建一个项目试试？
```

### 6.2 用户没填知识库

```
AI: 我用通用仙侠设定帮你继续。要更精准的话，建议先填《世界观规则》。

【继续按通用设定生成 3 个方向】
```

### 6.3 3 个方向都不满意

```
用户: "都不喜欢"
   ↓
AI: 好的，让我换个思路。

我重新生成 3 个方向，这次我会：
1. 加入更多反套路元素
2. 加强情感线
3. 强化某个配角

（10 秒后重新生成）
```

## 七、与其他协议的协同

### 7.1 stuck → continue

```
stuck 解决后：
   ↓
用户继续写下一章
   ↓
调用 protocol.entry_routing 入口 2
   ↓
调用 protocol.context_assembly（7 层上下文）
```

### 7.2 stuck → booming

```
如果 3 个方向都太平淡：
   ↓
调用 protocol.innovation_modules 的 booming
   ↓
生成 10 套高烈度掀桌方向
```

- **响应时间**：≤ 30 秒（生成 3 个方向 + 片段）

## 九、错误处理

### 9.1 卡点描述不清

```
🤔 你说的「张三」我有点不太明白。

你是哪个项目的主角？
A. 我的项目《XXX》的主角
B. 我没建项目，现在告诉你（继续告诉我）

或者告诉我更多细节？
```

### 9.2 3 方向生成失败

```
😅 AI 这会儿有点紧张，让我重新试试...

（10 秒后重试）
```

### 9.3 卡点太复杂

```
😊 你的卡点很复杂！我建议拆分成几个小问题。

先解决「这一章的主要目标是什么」？其他的我帮你逐步拆解。
```

## 十、与其他 skill 的差异

相比其他 skill 的"卡文处理"：
- tianming：没有专门的卡文协议
- MyNovel：通过修改大纲解决
- vibe-noveling：用 booming 掀桌

**本协议创新**：**"立即可用的 3 方向 + 片段"**——不是给抽象建议，是给具体可接续的 200 字片段。
