# 5 维质量评分协议（Quality Scoring Protocol）

[REF:protocol.quality_scoring]

## 一、设计哲学

**核心原则**（借鉴 PhosAQy）：**"宁可平庸，不可崩坏"**

5 维评分体系是 Auto-Novel Skill 的"质量守门人"——每章正文生成后必须通过评分（≥9.0）才能入库。

**为什么是 5 维？**
- 单维评分（如只看"流畅度"）容易被 AI 优化刷高
- 多维评分避免"偏科"——每个维度独立评估
- 维度权重根据**对故事崩坏的影响**分配

---

## 二、5 维评分体系

### 2.1 完整维度定义

| # | 维度 | 英文 | 权重 | 自动通过 | 人工复审 | 触发重写 |
|---|------|------|------|----------|----------|----------|
| 1 | **人设一致性** | OOC Consistency | 30% | ≥9.0 | 7.0-8.9 | < 7.0 |
| 2 | **世界观一致性** | Lore Consistency | 25% | ≥9.0 | 7.0-8.9 | < 7.0 |
| 3 | **逻辑性** | Logic | 20% | ≥9.0 | 7.0-8.9 | < 7.0 |
| 4 | **文风一致性** | Style Consistency | 15% | ≥9.0 | 7.0-8.9 | < 7.0 |
| 5 | **非重复性** | Non-Repetition | 10% | ≥9.0 | 7.0-8.9 | < 7.0 |
| **总评** | | | **100%** | **≥9.0** | **7.0-8.9** | **< 7.0** |

### 2.2 总评计算公式

```python
def calculate_overall_score(scores):
    """计算 5 维加权总分"""
    weights = {
        'ooc': 0.30,
        'lore': 0.25,
        'logic': 0.20,
        'style': 0.15,
        'repetition': 0.10
    }

    overall = sum(scores[dim] * weights[dim] for dim in weights)
    return round(overall, 2)
```

## 三、各维度的详细评估标准

### 3.1 维度 1：人设一致性（OOC Consistency）—— 权重 30%

**定义**：角色行为、语气、动机、价值观是否与既定设定一致。

**评估清单（10 项）**：

| # | 检查项 | 评分标准 |
|---|--------|----------|
| 1.1 | **语气一致** | 角色说话方式符合档案 |
| 1.2 | **动机合理** | 角色行为有合理动机 |
| 1.3 | **性格稳定** | 性格不突然大变 |
| 1.4 | **价值观一致** | 决策符合角色价值观 |
| 1.5 | **能力匹配** | 行为不超过角色能力 |
| 1.6 | **关系网络** | 角色关系前后一致 |
| 1.7 | **知识矩阵** | 角色知道/不知道的事正确 |
| 1.8 | **情绪连贯** | 情绪变化有合理铺垫 |
| 1.9 | **行为预测性** | 角色行为符合读者预期 |
| 1.10 | **人物弧光** | 角色成长符合规划 |

**评分计算**：
```python
ooc_score = sum(check_scores) / 10  # 10 项平均分
```

**示例 OOC 错误**：
```
第 15 章 · 张三
- ❌ 语气一致：张三突然用文绉绉的成语（档案显示他说话直白）
- ❌ 知识矩阵：张三知道"宗门内奸"（他在第 8 章才知道有线索）
- 评：每项扣 1 分，10 项合计 8 分
```

---

### 3.2 维度 2：世界观一致性（Lore Consistency）—— 权重 25%

**定义**：剧情是否遵守设定的硬规则（力量体系、经济规则、地理规则、社会规则）。

**评估清单（10 项）**：

| # | 检查项 | 评分标准 |
|---|--------|----------|
| 2.1 | **力量等级** | 修为/技能使用符合等级 |
| 2.2 | **技能限制** | 不超过已解锁能力的边界 |
| 2.3 | **经济体系** | 货币、价格、收入符合设定 |
| 2.4 | **地理距离** | 行程时间合理 |
| 2.5 | **时间季节** | 季节事件符合时间线 |
| 2.6 | **社会规则** | 等级礼法、宗门规矩遵守 |
| 2.7 | **文化习俗** | 节日、仪式、禁忌符合 |
| 2.8 | **政治结构** | 势力关系、权力分布一致 |
| 2.9 | **资源限制** | 不凭空获得资源 |
| 2.10 | **历史一致性** | 背景故事前后不矛盾 |

**评分计算**：同 OOC，10 项平均分。

---

### 3.3 维度 3：逻辑性（Logic）—— 权重 20%

**定义**：因果链是否完整、动机是否合理、不存在内部矛盾。

**评估清单（10 项）**：

| # | 检查项 | 评分标准 |
|---|--------|----------|
| 3.1 | **因果完整** | 因→果链路无断裂 |
| 3.2 | **动机清晰** | 角色行为有清晰动机 |
| 3.3 | **无逻辑跳跃** | 不突然冒出新设定 |
| 3.4 | **时间线合理** | 事件顺序符合物理时间 |
| 3.5 | **空间一致** | 角色位置不矛盾 |
| 3.6 | **身份一致** | 身份/马甲/角色不混乱 |
| 3.7 | **资源一致** | 资源消耗/获得平衡 |
| 3.8 | **伤势一致** | 伤势持续/恢复合理 |
| 3.9 | **情绪一致** | 情绪变化有铺垫 |
| 3.10 | **决策合理** | 角色决策有逻辑支撑 |

**评分计算**：同 OOC，10 项平均分。

---

### 3.4 维度 4：文风一致性（Style Consistency）—— 权重 15%

**定义**：是否与作者文风样本保持一致——句式、词汇、节奏、感官偏好。

**评估清单（10 项）**：

| # | 检查项 | 评分标准 |
|---|--------|----------|
| 4.1 | **段落长度** | 段落长度符合文风样本 |
| 4.2 | **句长分布** | 长短句比例符合 |
| 4.3 | **词汇偏好** | 高频词与禁用词符合 |
| 4.4 | **对话风格** | 角色对话方式一致 |
| 4.5 | **叙述视角** | 第一/第三人称一致 |
| 4.6 | **感官偏好** | 视觉/听觉/触觉侧重符合 |
| 4.7 | **节奏感** | 紧张/舒缓比例符合 |
| 4.8 | **修辞偏好** | 比喻/排比/反复使用符合 |
| 4.9 | **情绪表达** | Show vs Tell 比例符合 |
| 4.10 | **禁用表达** | 未使用作者禁用的词 |

**评分计算**：同 OOC，10 项平均分。

---

### 3.5 维度 5：非重复性（Non-Repetition）—— 权重 10%

**定义**：与已写章节相比，避免套路重复（情节、句式、词汇、转折）。

**评估清单（10 项）**：

| # | 检查项 | 评分标准 |
|---|--------|----------|
| 5.1 | **情节套路** | 不重复使用相同套路 |
| 5.2 | **转折方式** | 转折方式多样化 |
| 5.3 | **爽点设计** | 爽点类型多样化 |
| 5.4 | **句式重复** | 连续 3+ 句同结构扣分 |
| 5.5 | **形容词重复** | 同一章同一形容词 ≤ 3 次 |
| 5.6 | **比喻重复** | 比喻类型多样化 |
| 5.7 | **对话开头** | 不每次"道""说"开头 |
| 5.8 | **场景切换** | 场景转换方式多样化 |
| 5.9 | **情绪起伏** | 情绪曲线有变化 |
| 5.10 | **节奏变化** | 章节节奏有快慢变化 |

**评分计算**：同 OOC，10 项平均分。

## 四、评分执行流程

### 4.1 自动评分 vs 人工评分

**自动评分**（AI 评估）：
- 适用于：5 维全部指标
- 优点：快速、一致
- 缺点：可能漏掉细微问题

**人工评分**（用户评估）：
- 适用于：所有自动评分通过的章节（抽样）
- 优点：能发现 AI 看不到的问题
- 缺点：耗时、一致性差

### 4.2 评分流程

```
正文生成完成
   ↓
自动提取事实 → 生成事实锁
   ↓
5 维自动评分
   ↓
总评 ≥ 9.0？
   ├─ 是 → 自动通过 → 写入正式章节
   ├─ 7.0-8.9 → 人工复审 → 等待用户裁决
   └─ < 7.0 → 触发重写 → 返回 Step 3
```

### 4.3 评分报告

每章生成后输出【5 维评分报告】：

```
【5 维评分报告 · 第 12 章】

| 维度       | 评分 | 阈值 | 状态 |
|-----------|------|------|------|
| 人设一致性  | 9.2  | ≥9.0 | ✅ 通过 |
| 世界观一致性 | 9.5  | ≥9.0 | ✅ 通过 |
| 逻辑性      | 9.0  | ≥9.0 | ✅ 通过 |
| 文风一致性   | 8.5  | ≥9.0 | ⚠️ 复审 |
| 非重复性    | 9.3  | ≥9.0 | ✅ 通过 |
| **总评**    | **9.14** | **≥9.0** | **✅ 通过** |

【未通过项详情】
- 文风一致性 8.5：
  - ❌ 第 3 段：使用现代网络用语"YYDS"
  - ❌ 第 5 段：连续 5 句四字成语（过于堆砌）
  - 建议：删除网络用语 + 减少成语密度

【事实锁变更】
- 新增：3 条（张三在第 12 章获得 50 灵石、进入 16 强、获得新情报）
- 更新：1 条（透视符箓已用 1 次）
- 冲突：0 条 ✓
```

## 五、评分细节与边界

### 5.1 评分的客观性挑战

5 维评分本质上是**主观判断的形式化**——AI 评估 AI 输出会有偏差。

**缓解措施**：
- **多次评分取平均**：同一段文本评 3 次，取平均
- **多模型交叉验证**：用不同模型评分
- **关键维度阈值提高**：OOC 和 Lore（最影响崩坏）阈值 ≥ 9.5
- **用户抽样复核**：自动通过的章节 20% 抽样人工复核

### 5.2 评分阈值的可调性

不同题材的阈值不同：

| 题材 | OOC 阈值 | Lore 阈值 | Logic 阈值 | Style 阈值 | Repetition 阈值 |
|------|---------|----------|-----------|-----------|----------------|
| 玄幻/仙侠 | 9.5 | 9.5 | 9.0 | 9.0 | 9.0 |
| 都市/现代 | 9.0 | 9.0 | 9.5 | 9.0 | 9.0 |
| 悬疑/推理 | 9.5 | 9.0 | 9.5 | 9.0 | 9.0 |
| 言情/女频 | 9.0 | 9.0 | 9.0 | 9.5 | 9.0 |

### 5.3 评分与创作自由的平衡

**评分不是为了抹杀创作**，而是为了防止崩坏：

- 评分 < 7.0：硬崩坏，必须重写
- 评分 7.0-8.9：可改进，但作者可选择接受
- 评分 ≥ 9.0：质量达标，可发布
- 评分 ≥ 9.5：优秀，可作范例

## 六、重写机制

### 6.1 重写触发

```python
def should_rewrite(score, chapter_content):
    if score < 7.0:
        return True, "硬崩坏"
    elif score < 9.0 and any(
        check == 'critical' for check in chapter_content.critical_issues
    ):
        return True, "关键问题"
    else:
        return False, ""
```

### 6.2 重写策略

| 总评分 | 策略 |
|--------|------|
| < 5.0 | 整章重写 |
| 5.0-6.9 | 针对性修改（仅修改低分项） |
| 7.0-8.9 + 有关键问题 | 关键问题修正 |
| ≥ 9.0 | 通过 |

### 6.3 重写反馈循环

```
重写 → 重新评分
   ↓
评分提升？ 
   ├─ 是 → 进入下一轮重写（如未达标）
   └─ 否 → 触发人工复核
```

**最大重写次数**：3 次（避免无限循环）

## 七、与其他 skill 的差异

相比 PhosAQy 的 quality_scoring：
- PhosAQy：单次评分，无多次评分
- 本 skill：**3 次评分取平均** + **多模型交叉**

相比 webnovel-skills 的 review skill：
- webnovel：定性评估（5 维诊断）
- 本 skill：**定量评分**（每维 0-10 分）+ **自动通过/拒绝**

相比 tianming-skill 的"体检"协议：
- tianming：仅输出健康报告
- 本 skill：**强制通过阈值** + **重写机制**
