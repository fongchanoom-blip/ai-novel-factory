# 选题协议（Topic Selection Protocol）

[REF:protocol.topic_selection]

## 一、设计哲学

**核心原则**：**"好的开始是成功的一半"**

选题是小说创作的"基因"——选错题材，写作过程痛苦，读者也未必买单。

**为什么需要选题协议？**
- 创作者经常"什么都想写"，但**没有差异化**
- 不同平台的题材偏好不同（玄幻 vs 都市 vs 言情）
- 一个好选题 = 50% 成功 + 30% 留存

**核心策略**：
- ✅ **4 连问**锁定核心信息（频道/平台/题材/篇幅）
- ✅ **AI 生成 3 个差异化选题**（每个含卖点 + 类型 + 金手指）
- ✅ **基于 13 模块方法论库**的实战数据
- ✅ **可二次追问**（"我想要更热血的"）

## 三、完整流程

### 3.1 第 1 步：4 连问（30 秒）

**4 个关键问题**：

```
🤖 AI: 让我快速问你 4 个问题，帮你找到合适的选题！

❓ 问题 1/4：你想在哪个平台发布？
  1. 起点（玄幻/历史/都市，老白读者）
  2. 番茄（战神/系统/爽文，大众读者）
  3. 晋江（言情/耽美/百合，女性读者）
  4. 七猫（战神/爽文，下沉市场）
  5. 知乎盐选（悬疑/情感/职场，短篇为主）
  6. 不限定（先写再说）

❓ 问题 2/4：你想写什么题材？
  1. 玄幻 / 仙侠
  2. 都市 / 现代
  3. 言情 / 古风
  4. 悬疑 / 推理
  5. 科幻 / 未来
  6. 历史 / 军事
  7. 其他（告诉我）

❓ 问题 3/4：目标字数？
  1. 短篇（3-10 万字）
  2. 中篇（10-30 万字）
  3. 长篇（30-100 万字）
  4. 超长篇（100 万字+）

❓ 问题 4/4：你有灵感吗？
  1. 有完整的故事想法
  2. 有模糊的灵感
  3. 没有灵感，让我给你推荐
```

**特殊处理**：
- 如果用户说"我不懂"或"你帮我选" → 跳过该问题
- 如果用户中途说"算了" → 回到 `/novel:demo` 或 `/novel:quick`

### 3.2 第 2 步：AI 生成 3 个差异化选题（30-60 秒）

**生成 3 个选题，每个包含**：

```yaml
selection:
  id: TOPIC-1
  title: 逆天仙途                    # 暂定书名

  # 核心信息
  genre: 玄幻 / 仙侠
  platform: 起点
  length: 长篇（100 万字）

  # 1 句话定位
  pitch: 乙等下品废柴少年意外获得透视符箓，在宗门大比中一路逆袭，最终揭开自己"天灵根"的真实身份

  # 3 大卖点
  selling_points:
    - "废柴逆袭 + 透视符箓（爽点密集）"
    - "宗门大比的等级体系（沉浸感强）"
    - "主角身世悬念（长线钩子）"

  # 5 大核心元素
  elements:
    主角: 张三（乙等下品 → 天灵根）
    金手指: 透视符箓（每日 3 次）
    主线: 宗门崛起 + 身世揭秘
    卖点: 越级反杀 + 装逼打脸
    风格: 热血 + 阴谋

  # 类型对标
  similar_works:
    - 《凡人修仙传》（升级体系）
    - 《斗破苍穹》（废柴逆袭）
    - 《仙逆》（情感深度）

  # 预估市场表现
  market_estimate:
    平台适合度: ⭐⭐⭐⭐⭐
    题材热度: ⭐⭐⭐⭐
    写作难度: ⭐⭐⭐（中等）
    预期留存: ⭐⭐⭐⭐

  # 风险点
  risks:
    - 透视符箓需谨慎设计，避免"无敌感"
    - 废柴逆袭已饱和，需有差异化

  # 适合人群
  suitable_for:
    - 喜欢升级流的读者
    - 喜欢强情节的读者
    - 喜欢长篇的读者
```

### 3.3 第 3 步：用户选择（用户决策）

```
📚 我根据你的 4 个回答生成了 3 个差异化选题：

【选题 1：逆天仙途】⭐ 推荐
玄幻 / 仙侠 · 起点 · 长篇
"乙等下品废柴少年意外获得透视符箓，在宗门大比中一路逆袭"
- 卖点：爽点密集 + 长线钩子
- 难度：⭐⭐⭐
- 适合：喜欢升级流的读者

【选题 2：透视之眼】
都市 / 现代 · 番茄 · 中篇
"普通医学生获得透视眼，在商战中一路逆袭"
- 卖点：现代背景 + 强情节
- 难度：⭐⭐
- 适合：大众读者

【选题 3：废柴崛起录】
玄幻 / 仙侠 · 起点 · 长篇
"全家被灭的废柴少年，觉醒远古血脉"
- 卖点：复仇主线 + 血脉觉醒
- 难度：⭐⭐⭐⭐
- 适合：老白读者

你选哪个？

A. 选题 1（推荐）→ 继续到 /novel:outline
B. 选题 2
C. 选题 3
D. 都不喜欢 → 重新生成 3 个
E. 混合 1 和 2 → 我结合两个选题
```

### 3.4 第 4 步：细化（可选）

```
用户选 A：
   ↓
AI: 好的！你选了"逆天仙途"。

让我问几个细化问题（每个 5 秒）：

❓ 主角的开局设定？
  1. 完全废柴（最受虐）
  2. 中等资质 + 神秘金手指
  3. 强者伪装废柴（扮猪吃虎）
  4. 已有想法（告诉我）

❓ 你希望的金手指强度？
  1. 强（每日 10 次以上）→ 爽文
  2. 中（每日 3-5 次）→ 平衡
  3. 弱（每日 1-2 次）→ 烧脑
  4. 已有想法（告诉我）

❓ 你想要的情感线？
  1. 无（纯升级流）
  2. 1 条主线（师徒/伙伴）
  3. 多条（师徒 + 女主 + 兄弟）
  4. 已有想法（告诉我）

（回答后，AI 自动生成完整的世界基石 + 角色档案）
```

## 四、3 个选题的差异化设计

### 4.1 选题 A：稳妥版

**特征**：
- 经典套路（废柴逆袭、系统、重生）
- 经过市场验证
- 风险低

**适用**：第一次写、想稳定输出、目标签约

### 4.2 选题 B：创新版

**特征**：
- 加 1-2 个反套路元素
- 差异化定位
- 风险中

**适用**：有一定经验、想脱颖而出

### 4.3 选题 C：细分版

**特征**：
- 聚焦特定细分市场
- 竞争较小
- 风险高

**适用**：有特定读者群

## 六、用户输入的特殊处理

### 6.1 用户说"我不懂"

```
AI: 没关系，我帮你选！基于你「不限定平台」，我推荐番茄系。

原因：
- 番茄读者多，需求广
- 写作难度较低
- 适合新手

你感兴趣吗？
A. 好，按番茄系
B. 我想更详细了解
```

### 6.2 用户说"我有一个想法"

```
AI: 太好了！告诉我你的想法，可以是：
- 1 句话
- 几个关键词
- 一段描述

（接收用户的灵感）
   ↓
AI: 基于你的灵感，我生成 3 个延伸的选题...
```

### 6.3 用户说"我不喜欢这 3 个"

```
AI: 好的，让我重新生成。这次我会：
1. 避开你之前不喜欢的元素
2. 引入新的元素
3. 改变核心设定

（重新生成 3 个）
```

## 八、错误处理

### 8.1 平台与题材不匹配

```
⚠️ 我注意到你选了"起点 + 言情"，但起点以玄幻/历史/都市为主。

建议：
- 改成"晋江 + 言情"
- 或者"起点 + 玄幻"（但加言情元素）

你想？
A. 改平台（晋江）
B. 改题材（玄幻）
C. 忽略警告
```

### 8.2 选题生成失败

```
😅 AI 这会儿没灵感，让我重新生成...
（10 秒后重试）
```

## 九、性能要求

- **响应时间**：≤ 60 秒（4 连问 + 3 选题生成）
- **3 个选题**：每个含完整信息（卖点 + 元素 + 对标 + 评估）
- **4 连问**：每个 5-10 秒

---

## 十、与其他 skill 的差异

相比其他 skill 的"选题"：
- tianming：没有专门的选题协议
- MyNovel：直接进入大纲，没有差异化选题
- webnovel：散落在多个 references/

**本协议创新**：**"4 连问 + 3 差异化选题 + 平台特性数据库"**——基于实战数据，不靠"感觉"。
