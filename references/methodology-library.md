## 模块 1：反 AI 检测（novel-anti-detection）

### 触发问题
- "AI 写的文怎么才能不被检测出来？"
- "平台现在对 AI 写作是什么政策？"
- "怎么设计 AI + 人工混合创作的流程？"
- "AIGC 检测的原理是什么？"

### 核心方法论

**AIGC 检测的 3 大原理**：

1. **困惑度检测**：AI 文本的 perplexity 异常低（用词过于"安全"）
2. **突发性检测**：AI 文本的 burstiness 异常低（句子长度过于均匀）
3. **风格指纹**：训练数据中的常见模式（如"然而""因此""综上所述"）

**反检测的 3 大策略**：

| 策略 | 实施方法 |
|------|----------|
| **人工改写** | AI 生成 → 人工调整 30-50% 内容 |
| **混合创作** | AI 提供素材 → 人工串联 |
| **风格迁移** | AI 模仿作者文风 → 人工微调 |

**关键原则**：
- 不试图"骗过检测"，而是"创作自然"
- 真正像人写的文不需要反检测
- 平台政策在变化（2026 年已有多家平台限制纯 AI 作品）

## 模块 2：人设设计（novel-character-design）

### 触发问题
- "帮我设计一个主角性格"
- "配角怎么写才不工具人？"
- "反派怎么塑造才更有魅力？"

### 核心方法论

**主角设计的 5 维度**：

| 维度 | 描述 |
|------|------|
| **背景** | 出身、成长环境、关键经历 |
| **性格** | 主导特质 + 弱点 + 矛盾 |
| **动机** | 表层目标 + 深层动机 |
| **能力** | 起始能力 + 成长曲线 + 限制 |
| **关系** | 与重要角色的关系网络 |

**配角工具化的 3 反模式**：

1. **传声筒型**——只为传递信息
2. **升级机型**——只为推动主角升级
3. **对照机型**——只为衬托主角

**反派的 5 级塑造**：

| 级别 | 描述 |
|------|------|
| L1 纸老虎 | 单纯被主角碾压 |
| L2 强敌 | 有真实威胁 |
| L3 智者 | 智商在线 |
| L4 立体 | 有自己的信念 |
| L5 镜像 | 与主角形成对照 |

## 模块 4：合规与敏感词（novel-compliance）

### 触发问题
- "平台审核都查什么？"
- "敏感词怎么规避？"
- "2026 年 AI 写作的法规要求？"

### 核心方法论

**4 大合规红线**：

| 红线 | 说明 |
|------|------|
| **政治安全** | 不可涉及国家领导人、政治敏感事件 |
| **色情低俗** | 不可有露骨性描写 |
| **暴力血腥** | 不可过分渲染暴力 |
| **AI 标注** | 多平台要求 AI 辅助作品标注 |

**敏感词规避的 3 技巧**：
1. **同义替换**：找合规的同义词
2. **隐喻表达**：用比喻代替直白
3. **场景转移**：将敏感场景"留白"

**2026 年最新法规**：
- 多平台要求 AI 辅助作品标注"AI 辅助创作"
- 部分平台限制纯 AI 作品
- 内容审查 AI 化（不仅人工）

## 模块 5：情绪与代入感（novel-emotion）

### 触发问题
- "怎么让读者有代入感？"
- "催泪/共情的桥段怎么设计？"

### 核心方法论

**代入感的 3 大要素**：

1. **角色相似度**：读者与角色的共鸣点
2. **情境相似度**：读者经历过类似情境
3. **细节真实度**：描写是否到位

**情绪刻画的 Show vs Tell 原则**：

```
❌ Tell（告诉）：
"他非常难过。"

✓ Show（展现）：
"他盯着那张照片，手指微微颤抖，眼眶里有什么东西在打转。"
```

**5 种情绪的展现技巧**：

| 情绪 | 展现方式 |
|------|----------|
| 悲伤 | 动作迟缓 + 眼神涣散 + 长时间沉默 |
| 愤怒 | 拳头紧握 + 呼吸急促 + 嘴角抽搐 |
| 恐惧 | 瞳孔放大 + 手心出汗 + 后退一步 |
| 喜悦 | 笑容绽放 + 步伐轻快 + 语调上扬 |
| 紧张 | 喉咙发干 + 心跳加速 + 反复确认 |

## 模块 6：题材与融合（novel-genres）

### 触发问题
- "玄幻和仙侠有什么区别？"
- "我想把科幻和修仙融合，能行吗？"

### 核心方法论

**9 大题材分类（参考 webnovel-skills）**：

| 题材 | 核心套路 | 爽点类型 |
|------|----------|----------|
| 玄幻 | 升级打怪 + 异世界 | 越级反杀 |
| 仙侠 | 修真飞升 + 道法自然 | 顿悟突破 |
| 都市 | 装逼打脸 + 商战 | 实力展示 |
| 悬疑 | 推理揭秘 + 心理博弈 | 真相大白 |
| 科幻 | 科技设定 + 文明冲突 | 黑科技碾压 |
| 历史 | 穿越改变 + 权谋 | 历史名人 |
| 言情 | 情感纠葛 + 误会解除 | 终成眷属 |

**融合的 3 个原则**：

## 模块 7：创新与反套路（novel-innovation）

### 触发问题
- "套路都用烂了，怎么写出新意？"
- "有没有反套路的写法可以参考？"

### 核心方法论

**8 大套路识别**：

| 套路 | 模式 | 风险 |
|------|------|------|
| 废柴逆袭 | 主角一开始弱 | 烂大街 |
| 扮猪吃虎 | 隐藏实力 | 滥用 |
| 打脸四拍 | 铺垫→嘲讽→爆发→收束 | 同质化 |
| 系统流 | 突然获得系统 | 趋于饱和 |
| 重生复仇 | 重生回到过去 | 套路化 |
| 穿越改变 | 现代人到古代 | 常见 |
| 强设定升级 | 等级明确 | 缺新鲜感 |
| 多女主/男主 | 感情线众多 | 模板化 |

**反套路的 5 大策略**：

1. **角色反套路**：让"反派"有合理信念
2. **情节反套路**：在套路关键节点"刹车"
3. **设定反套路**：废设定或简化设定
4. **节奏反套路**：快慢结合
5. **主题反套路**：表达深刻主题

## 模块 8：语言与文风（novel-language-style）

### 触发问题
- "怎么确定自己的文风？"
- "叙述视角怎么选择？"

### 核心方法论

**文风的 4 维度**：

| 维度 | 选项 |
|------|------|
| **句长** | 短句（紧张）/ 中句（平实）/ 长句（抒情） |
| **词汇** | 通俗 / 半文半白 / 古典 |
| **节奏** | 快（爽文）/ 中（普通）/ 慢（文艺） |
| **感官** | 视觉主导 / 听觉主导 / 多感官 |

**叙述视角的 4 种选择**：

| 视角 | 优点 | 缺点 | 适合题材 |
|------|------|------|----------|
| 第一人称（"我"）| 代入感强 | 信息有限 | 言情、悬疑 |
| 第二人称 | 罕见、新奇 | 不自然 | 罕见 |
| 第三人称限知 | 平衡 | 切换频繁 | 玄幻、都市 |
| 第三人称全知 | 信息量大 | 代入感弱 | 历史、群像 |

**文风稳定的 3 大方法**：
1. **文风样本锚定**：每章参考 2-3 个最相似的段落
2. **禁用表达清单**：列出绝对不要使用的词
3. **定期回顾**：每 5 章回顾一次文风是否漂移

## 模块 9：节奏与结构（novel-pacing）

### 触发问题
- "开头怎么写才能抓住人？"
- "断章怎么断才让读者追更？"

### 核心方法论

**黄金三章结构**：

| 章 | 目标 | 关键 |
|----|------|------|
| 第 1 章 | 立人设 + 出冲突 | 3 句内立危机 |
| 第 2 章 | 扩大冲突 + 小爽点 | 第一次"反杀" |
| 第 3 章 | 第一个高潮 + 主线悬念 | 决定收藏率 |

**断章钩的 5 大类型**：

1. **悬念型**："我没想到，第二天她竟然出现在我房门口"
2. **反转型**："原来这就是她十年来一直隐藏的真相"
3. **战斗型**："下一章，他们将正面对决"
4. **情感型**："这一刻，她终于明白了自己真正的心意"
5. **伏笔型**："那封压在抽屉里 20 年的信，即将重见天日"

**节奏呼吸感**：

```
紧张（战斗/打脸）→ 短暂舒缓（日常/感情）→ 紧张升级
   ↓                  ↓                  ↓
   3 章             1 章              5 章
```

### 触发问题
- "爽点怎么设计才够爽？"
- "扮猪吃虎的模板是什么？"

**10 大爽点类型**：

| 爽点 | 触发 | 强度 |
|------|------|------|
| 越级反杀 | 弱胜强 | ★★★★ |
| 装逼打脸 | 嘲讽后爆发 | ★★★★★ |
| 扮猪吃虎 | 隐藏后反转 | ★★★★ |
| 真相大白 | 谜底揭示 | ★★★ |
| 逆袭翻盘 | 绝境逆转 | ★★★★★ |
| 一鸣惊人 | 默默无闻者突起 | ★★★ |
| 收获奖励 | 实力提升 | ★★ |
| 感情成功 | 终成眷属 | ★★★ |
| 复仇成功 | 报仇雪恨 | ★★★★★ |

**爽点密度的合理区间**：
- 番茄系：每章 1-2 个爽点

1. **多样化**：轮换不同类型

3. **组合**：多个小爽点组合成大爽点
4. **延迟**：故意延后某些爽点

## 模块 11：润色与去 AI 味（novel-polishing）

### 触发问题
- "AI 写的文怎么改才像人写的？"
- "对话太生硬了，怎么润色？"

### 核心方法论

**AI 味的 12 大信号**：

1. **比喻三连**："像...似...宛如..."
2. **转折词滥用**："然而""与此同时"
3. **连续同句式**：连续 3+ 句同结构
4. **句长过均**：一段内句子长度差异小
5. **总结句**：每段最后来一句"这一刻..."
6. **tell 多于 show**：直接说情绪而非展现
7. **极端词堆砌**："非常""极其""顿时"
8. **形容词重复**：同一形容词在一章出现多次
9. **修辞过度**：每段都有修辞
10. **段落分布**：每段长度相近
11. **对话生硬**：每句对话都是完美回应
12. **缺乏个人化**：缺少作者独特表达

**润色的 5 大方法**：

| 方法 | 描述 |
|------|------|
| **删减法** | 删除 30% 的修辞和形容词 |
| **替换法** | 用"几乎不""差不多"替代"非常" |
| **重组法** | 重新组织句子结构 |
| **口语化** | 加入口语化表达 |
| **细节化** | 用具体细节替代抽象形容 |

## 模块 13：世界观与设定（novel-worldbuilding）

### 触发问题
- "修仙体系怎么设计？"
- "地图和势力格局怎么规划？"

### 核心方法论

**力量体系的 5 要素**：

| 要素 | 描述 |
|------|------|
| **等级** | 划分 5-10 个等级 |
| **升级条件** | 每级升级的要求 |
| **技能限制** | 每级可使用的技能 |
| **代价** | 升级的代价（资源/时间/风险）|
| **上限** | 体系的最高境界 |

**地图设计的 3 原则**：

1. **距离合理**：A 到 B 需要 X 时间
2. **势力分布**：各势力占据关键位置
3. **冲突地带**：可触发剧情的关键地点

**经济体系的 4 要素**：

1. **货币**：基础 + 高级（如铜钱/灵石）
2. **物价**：不同档次的物品价格
3. **收入**：各角色群体的收入水平
4. **流通**：货币在各群体间的流动

**前后矛盾检测清单**：
- ✓ 地图距离是否一致？
- ✓ 势力分布是否前后矛盾？
- ✓ 经济体系是否合理？
- ✓ 力量体系是否有规则破坏？
