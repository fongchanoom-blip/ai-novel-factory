# 世界观规则 · 玄幻仙侠模板

## 力量体系（核心设定）

```yaml
境界等级:
  练气期:
    段位: 1-9 层
    寿命: 与凡人同
    能力: 感知灵气/初步使用符箓
    突破条件: 吸收灵气，凝聚气旋
    限制: 不可御剑飞行

  筑基期:
    段位: 1-9 层
    寿命: 150 年
    能力: 御器飞行/法术初成
    突破条件: 凝结道基
    限制: 不可长时间飞行

  金丹期:
    段位: 1-9 层
    寿命: 500 年
    能力: 御剑飞行/法术大成
    突破条件: 凝结金丹
    限制: 高阶法术受限

  元婴期:
    段位: 1-9 层
    寿命: 1000 年
    能力: 瞬移/法术圆满
    突破条件: 修成元婴
    限制: 天劫威压

  化神期:
    段位: 1-9 层
    寿命: 2000 年
    能力: 沟通天地
    突破条件: 领悟法则
    限制: 飞升天劫
```

## 灵根体系

```yaml
灵根等级:
  天灵根: 单一灵根，修炼速度 10x
  异灵根: 变异灵根（如雷、冰、风），5-8x
  双灵根: 两种属性，3-5x
  三灵根: 三种属性，2x
  四灵根/五灵根（废灵根）: 1x 或更慢
```

## 宗门等级

```yaml
宗门规模:
  超品宗门: 1 个（如：天道宗）
  一品宗门: 5-10 个（如：青云宗、蜀山剑派）
  二品宗门: 数十个
  三品宗门: 上百个
  散修: 无数

宗门架构:
  宗主 → 长老 → 护法 → 内门弟子 → 外门弟子 → 杂役
```

# 文风样本 · 玄幻仙侠模板

> 粘贴 2-3 段你喜欢的玄幻小说片段，让 AI 学习你的文风。

## 整体风格

```yaml
题材: 玄幻/仙侠
基调: 热血 + 阴谋
视角: 第三人称限知
```

## 句式偏好

```yaml
常用句式:
  - "我深吸一口气，..."
  - "门后是一片漆黑，但..."
  - "我不说话。只是..."
  - "主考官摇了摇头，..."
  - "然而这一刻，我等了三年。"

修辞特点:
  - 短句多（营造紧张感）
  - 大量"我不说话/我没动"（内心戏）
  - 省略号频繁使用（欲言又止）
```

## 词汇偏好

```yaml
古风词汇:
  使用:
    - 筑基期/金丹期/元婴期
    - 灵石/法器/符箓
    - 师父/师兄/师姐
    - 罢了/也罢/且慢
  禁用:
    - 现代网络用语
    - 外语词汇（除功法名）
    - 简化字（如：哪个→哪个）
```

## 段落节奏

```yaml
段落长度:
  短段: 30-80 字（动作/对话）
  中段: 80-150 字（叙述）
  长段: 150-300 字（心理/描写）

节奏控制:
  - 每 500 字必有 1 个爽点
  - 每章必有 1 个反转
  - 每卷必有 1 个大高潮
```

## 禁止风格

```yaml
禁用表达:
  - "瞳孔一缩"
  - "震惊无比"
  - "简直不敢相信"
  - "然而他不知道的是"
  - "与此同时，在遥远的..."
  - "我一定会回来的！"
  - AI 味套路结尾（"原来如此..."）
```

**📖 使用方法**：
1. 复制本目录到 `~/auto-novel-projects/<你的项目>/`
2. 修改对应字段（如：主角姓名、修为等）
3. 运行 `python3 kb_manager.py <项目目录> validate` 验证

**🚀 创作者建议**：
- 起名时尽量用 2-3 字中文名（修仙界通用）
- 金手指设计要有限制（否则剧情无力）
- 至少设计 3 个反派（阶段不同）
