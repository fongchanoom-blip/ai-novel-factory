## 文风样本 · 都市现代

### 整体风格

```yaml
题材: 都市/现代
基调: 热血 + 情感
视角: 第一人称/第三人称
```

### 句式偏好

```yaml
常用句式:
  - "我深吸一口气，..."
  - "那一刻，我才知道..."
  - "我冷笑一声，..."
  - "你说什么？"
  - "周围的人都惊呆了。"

修辞特点:
  - 短句制造爽感
  - 大量对话
  - 内心独白
```

### 词汇偏好

```yaml
现代词汇:
  使用:
    - 房地产/金融/互联网
    - CEO/总裁/董事
    - 跑车/名表/红酒
    - 谈判/合同/股市
  禁用:
    - 古风词汇（如：筑基期）
    - 修仙术语
    - 仙侠概念
```

### 节奏控制

```yaml
段落长度:
  短段: 30-80 字（对话/动作）
  中段: 80-150 字（叙述）

节奏:
  - 每 500 字必有 1 个爽点
  - 每章必有 1 个反转
  - 感情线 + 事业线并行
```

### 禁止风格

```yaml
禁用表达:
  - "瞳孔一缩"
  - "震惊无比"
  - "简直是..."
  - "然而他不知道的是"
  - 修仙味套路
```

**📖 使用方法**：
1. 复制到 `~/auto-novel-projects/<你的项目>/`
2. 修改主角姓名/金手指
4. 运行 `python3 kb_manager.py validate`

**🚀 创作者建议**：
- 金手指要符合现实逻辑（如：鉴宝、医术）
- 至少 2 个女主（避免单调）
- 反派要有真实背景（不只是脸谱化）
