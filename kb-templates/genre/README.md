## 🚀 使用方法

### 方式 1：kb_manager 自动加载

```bash
python3 scripts/kb_manager.py ~/my-novel init --genre 玄幻仙侠
```

（v1.0.7 计划：自动识别 genre 参数）

### 方式 2：手动复制

```bash
cp -r kb-templates/genre/玄幻仙侠/* ~/my-novel/
```

### 方式 3：Web 界面（v1.0.7+）

项目仪表盘 → 创建项目时选择题材 → 自动加载对应模板

## 📋 每个模板包含什么

每个题材模板是一份"大文档"，包含以下 5 个部分（用 YAML 代码块分隔）：

| 部分 | 内容 | 用户填写量 |
|------|------|----------|
| **世界基石** | 主角状态 + 主线进度 + 爽点追踪 | 30% |
| **世界观规则** | 力量等级 + 经济体系 + 地理 | 20% |
| **角色档案** | 主角/女主/反派/配角详细设定 | 50% |
| **档案事件** | 已发生事件 + 未发生事件 + 伏笔追踪 | 持续维护 |
| **文风样本** | 句式/词汇/段落/禁用表达 | 粘贴 2-3 段样本 |

## 🎯 题材选择指南

### 我不知道选什么？

**答：根据你想写的"爽点"决定。**

| 爽点 | 推荐题材 |
|------|----------|
| 打脸、装逼、修炼、战斗 | **玄幻仙侠** |
| 逆袭、商战、鉴宝、神医 | **都市现代** |
| 误会、虐恋、甜蜜、圆满 | **言情古风** |
| 推理、烧脑、反转、真相 | **悬疑推理** |
| 太空、AI、外星、文明 | **科幻未来** |

### 我想写的题材没有模板？

**答**：用通用模板（`kb-templates/` 顶层 5 个文件）+ 自己补充设定。

或联系作者补全模板。

## 🛠️ 模板维护说明

### 模板作者

每个模板都是该题材资深作者的**共识**：
- 玄幻：参考《凡人修仙传》《仙逆》《诛仙》
- 都市：参考《我欲封天》《最强弃少》《天才相师》
- 言情：参考《步步惊心》《甄嬛传》《何以笙箫默》
- 悬疑：参考《白夜追凶》《无证之罪》《嫌疑人 X 的献身》
- 科幻：参考《三体》《基地》《海伯利安》

### 模板约定

每个模板都遵循：
- ✅ 至少 3 个爽点模板（贯穿全文）
- ✅ 至少 2 个反派（不同阶段）
- ✅ 至少 2 条感情线（避免单调）
- ✅ 完整的力量/经济/地理体系
- ✅ 至少 5 个禁用表达（避免 AI 味）
