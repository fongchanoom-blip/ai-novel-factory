## 文风样本 · 言情古风

### 整体风格

```yaml
题材: 言情/古风
基调: 柔情/虐恋
视角: 第一人称/第三人称
```

### 句式偏好

```yaml
常用句式:
  - "我低头敛眉，轻声道：..."
  - "他朝我看来，目光幽深..."
  - "那一刻，我的心仿佛..."
  - "轻罗小扇白兰花，..."
  - "回眸一笑百媚生..."

修辞特点:
  - 古诗词化用
  - 大量比喻（花、月、水）
  - 心理描写细腻
```

### 词汇偏好

```yaml
古风词汇:
  使用:
    - 妾身/小女子/奴家
    - 公子/夫人/小姐
    - 玉佩/香囊/罗帕
    - 望/盼/忆/思
    - 罢了/也罢/且慢
  禁用:
    - 现代网络用语
    - 简化字过度使用
    - 西式表达
```

### 段落节奏

```yaml
段落长度:
  短段: 30-80 字（对话/动作）
  中段: 80-150 字（心理/景物）

节奏:
  - 每章必有情感波动
  - 每卷必有 1 次大虐
  - 每卷必有 1 次甜
  - 每 5 章必有 1 次误会
```

### 禁止风格

```yaml
禁用表达:
  - "瞳孔一缩"
  - "震惊无比"
  - "简直是..."
  - 古风+现代混搭
  - 修仙术语
```

**📖 使用方法**：
1. 复制到 `~/auto-novel-projects/<你的项目>/`
2. 修改朝代背景（架空或真实）
3. 设计男女主身份 + 误会点

**🚀 创作者建议**：
- 男女主身份要门当户对（避免太夸张）
- 误会要有合理性（不能强行制造）
- 反派女配要有动机（不只是脸谱化）
- 情感线要有层次（暗恋→误解→真相→圆满）
