# 角色档案模板（Character Profiles）

> **用户必须填写**——所有重要角色的详细档案。

---

## 主角

```yaml
主角:
  基本信息:
    姓名: （必填）
    年龄: （必填）
    性别: （必填）

  外貌: （如：清秀少年，约 17 岁）

  性格:
    主导特质: （如：谨慎、机智）
    弱点: （如：过于保守）
    矛盾: （如：谨慎 vs 复仇心切）

  动机:
    表层目标: （如：通过宗门大比）
    深层动机: （如：为父报仇 + 求道长生）

  能力:
    起始能力: []
    成长曲线: （如：第 X 章获得透视符箓）
    限制: （如：每日最多 3 次）

  关键关系:
    - 角色: （必填）
      关系类型: （如：暗恋/敬重/仇恨）
      重要度: 高/中/低
```

## 填写示例

### 主角示例（仙侠）

```yaml
主角:
  基本信息:
    姓名: 张三
    年龄: 18
    性别: 男

  外貌: 清秀少年，约 17 岁，眼神坚定

  性格:
    主导特质: 谨慎、机智、有底线
    弱点: 过于保守、偶尔心软
    矛盾: 谨慎 vs 复仇心切

  动机:
    表层目标: 通过宗门大比，进入内门
    深层动机: 为父报仇 + 求道长生

  能力:
    起始能力: [基础剑法]
    成长曲线: 第 5 章获得透视符箓
    限制: 每日最多 3 次

  关键关系:
    - 角色: 师姐（李清）
      关系类型: 暗恋
      重要度: 高
    - 角色: 师父（李青云）
      关系类型: 敬重
      重要度: 高
```

### 反派示例

```yaml
反派1:
  姓名: 赵无极
  身份: 内门长老之子
  实力: 金丹期
  动机: 觊觎掌门之位，陷害主角
  智商等级: L3（智者）
  与主角冲突: 宗门大比中的对手 + 师姐失踪的幕后黑手
  重要度: 高
```

## ⚠️ 角色一致性约束

**5 维评分中的"人设一致性"权重 30%**——任何角色行为如果违反本档案，会被扣分：

| 违反类型 | 扣分 |
|---------|------|
| 性格突然大变 | 1.0+ |
| 动机前后矛盾 | 0.5+ |
| 关系网络错乱 | 0.5+ |
| 知识矩阵错位 | 1.0+ |
