```yaml
力量等级:
  - 等级1: （如：筑基期）
    能力: []
    限制: []

  - 等级2: （如：金丹期）
    能力: []
    限制: []

  # ...更多等级

  升级条件:
    等级1→2: （如：需要 X 灵石 + Y 天修炼）
    等级2→3: ...

体系上限: （如：化神期不可在凡间出手）
```

## 经济体系

```yaml
货币:
  基础货币: （如：灵石 / 银两 / 元）
  高级货币: （如：仙晶）

物价基准:
  1基础货币: = 普通人家1月开销

收入水平:
  普通村民: X /月
  宗门外门弟子: X /月
  宗门内门弟子: X /月

流通规则:
  底层: 基础货币
  上层: 高级货币
  兑换率: 1高级 = X 基础
```

## 地理规则

```yaml
主要地点:
  - 地点A: （如：青云宗）
    距离最近城镇: X 天
    季节限制: 大雪封山 11-2 月

  - 地点B: （如：最近城镇）
    距离A: X 天

季节:
  春季: 3-5 月
  夏季: 6-8 月
  秋季: 9-11 月
  冬季: 12-2 月
```

## 填写示例

### 力量体系示例（仙侠）

```yaml
力量等级:
  - 等级1: 筑基期
    能力: [低阶符箓, 内息运转]
    限制: [不能御剑飞行]

  - 等级2: 金丹期
    能力: [御剑飞行, 中阶符箓]
    限制: [不能瞬移]

  # ...

体系上限: 化神期禁止在凡间出手（天道约束）
```

### 经济体系示例

```yaml
货币:
  基础货币: 灵石
  高级货币: 仙晶（10000 灵石 = 1 仙晶）

物价基准:
  1灵石 ≈ 普通人家 1 月开销

收入水平:
  普通村民: 0 灵石（自给自足）
  宗门外门弟子: 10 灵石/月
  宗门内门弟子: 100 灵石/月
```

## ⚠️ 硬规则使用方式

**正文写作时**：
- 每条剧情/描写都必须符合本文件规则
- 违反规则的章节 → 5 维评分中的"世界观一致性"会被扣分
- 严重违反 → 触发一致性重写

**修改本文件时**：
- ⚠️ 已写章节的事实锁可能失效
- 建议修改后重跑一致性检查
